# 파일 일괄 수정 (ls / grep / sed)

## 숫자가 섞인 경로를 숫자 순으로 나열

```bash
ls -lv <files>
```

- **언제**: 번호 붙은 파일·디렉터리를 1, 2, 3 순서로 보고 싶을 때
- **주의**: `<files>`에는 `data*/conf/app.yml`처럼 `*`를 넣어 여러 파일을 한 번에 지정한다. `*`는 "아무 글자나 몇 개든"이라는 뜻이고, 셸이 실행 전에 맞는 파일 이름들로 바꿔 넣는다
- **주의**: 셸이 `*`를 펼칠 때와 기본 `ls`는 글자 단위 사전순으로 정렬한다. 그래서 첫 글자 `1`이 `2`보다 작다고 보고 `10`이 `2`보다 앞에 온다. `-v`를 주면 `10`을 숫자 10으로 읽어서 2 < 3 < ... < 10 순서가 된다
- **주의**: `-v`는 리눅스 `ls`에만 있다. macOS 기본 `ls`엔 없다

## 여러 파일을 숫자 순으로 grep

```bash
ls -v <files> | xargs grep -H <keyword>
```

- **언제**: 여러 파일을 순서대로 grep할 때. 수정 전후 확인용
- **주의**: `grep <keyword> data*/...`처럼 바로 쓰면 셸이 `*`를 사전순으로 펼쳐서 순서가 꼬인다. `ls -v`로 파일 목록을 먼저 정렬하고, `xargs`가 그 목록을 `grep` 뒤에 붙여서 실행한다
- **주의**: `-H`가 있어야 줄 앞에 파일명이 붙는다
- **연관**: `grep ... | sort -V`로 결과를 정렬해도 되지만, 한 파일에서 여러 줄 걸리면 파일 안의 줄 순서까지 섞인다
- **연관**: 다음 줄까지 보려면 `-A1`. 찾을 문자열이 `-`로 시작하면 옵션으로 오해하니 앞에 `--`를 붙인다

## 치환 결과 미리보기

```bash
sed -n 's/<pattern>//p' <files>
```

- **언제**: `sed -i`로 고치기 전에 바뀔 줄만 확인할 때
- **주의**: `-n`은 sed가 모든 줄을 출력하는 걸 끄고, 끝의 `p`는 바뀐 줄만 출력한다. 파일은 바뀌지 않는다

## 여러 파일에서 문자열 일괄 삭제

```bash
sudo sed -i.bak 's/<pattern>//' <files>
```

- **언제**: 여러 파일에서 같은 문자열을 한 번에 지울 때
- **주의**: `s/찾을것/바꿀것/`에서 바꿀 것을 비워 두면 삭제가 된다
- **주의**: `<pattern>` 안의 `*`는 파일 지정할 때의 `*`와 뜻이 다르다. 여기선 "바로 앞 글자가 0번 이상 반복"이다. `[0-9]*`는 "숫자가 몇 개든"
- **주의**: sed에서 `|`는 특별한 의미가 없는 그냥 글자라 앞에 `\`를 붙이지 않고 그대로 쓴다
- **주의**: `-i.bak`은 파일을 직접 고치고 원본을 `.bak`으로 남긴다. 실행할 때마다 `.bak`이 덮어써지니, 맨 처음 원본이 필요하면 첫 `.bak`을 다른 이름으로 옮겨둔다
- **주의**: root로 `sed -i`를 실행해도 원래 파일의 소유자와 권한은 그대로 유지된다
- **연관**: 쉼표로 나열된 목록에서 항목 하나 지우기 — `s/, <word>\b//`. 앞 쉼표까지 지워야 목록이 깔끔하다. `\b`는 "단어가 여기서 끝남"이라는 뜻이라 `<word>2`처럼 이름이 비슷한 항목은 안 걸린다. 목록 맨 앞 항목은 `<word>, ` 형태라 이 패턴에 안 걸린다

## 특정 줄과 다음 줄을 함께 삭제

```bash
sudo sed -i.bak '/<first_line>$/{N;/<next_keyword>/d}' <files>
```

- **언제**: YAML 리스트 항목처럼 두 줄짜리 블록을 빼낼 때
- **주의**: `<first_line>`에 맞는 줄을 찾으면 `N`이 다음 줄을 읽어 붙인다. 붙인 두 줄에 `<next_keyword>`가 있을 때만 `d`로 둘 다 지운다. 다음 줄이 예상과 다르면 지우지 않는다
- **주의**: `$`는 "줄 끝"이라는 뜻이다. 붙여야 `crawler2`처럼 뒤에 글자가 더 있는 줄이 안 걸린다
- **연관**: 미리보기는 `-i` 없이 돌려서 원본과 비교 — `sed '<script>' <file> | diff <file> -` (`-`는 앞 명령의 출력을 받는다는 뜻)

## sed 백업 파일 일괄 삭제

```bash
sudo rm -f <files>.bak
```

- **언제**: `sed -i.bak` 결과를 확인한 뒤 백업을 정리할 때
- **주의**: 먼저 `ls -lv <files>.bak`로 목록을 확인한다
- **연관**: 위치가 흩어져 있으면 `find <dir> -name '<name>.bak' -print`로 확인한 뒤 `-print`를 `-delete`로 바꿔 지운다
