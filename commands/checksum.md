# 체크섬

## 공개된 SHA256 값으로 파일 검증

```bash
echo "<sha256>  <file>" | sha256sum -c -
```

- **언제**: 다운로드한 파일(JDK 압축 파일, 설치 파일 등)이 배포처가 공개한 SHA256 값과 같은지 확인할 때. 체크섬 파일 없이 해시 문자열만 받은 경우에 쓴다
- **주의**: SHA256은 파일 내용으로 계산한 64자리 값이다. 1바이트만 달라도 값이 완전히 바뀌므로, 값이 같으면 받는 도중 깨지거나 바뀌지 않았다고 볼 수 있다
- **주의**: `-c`는 입력을 `해시  파일명` 목록으로 읽고, 그 파일을 다시 계산해 비교한다. 끝의 `-`는 목록을 파일 대신 표준입력에서 읽으라는 뜻이다. 결과는 `<file>: OK` 또는 `FAILED`로 나온다
- **주의**: 해시와 파일명 사이는 **공백 2칸**이 표준 형식이고, 반드시 한 따옴표 안에 넣는다. `echo "<sha256>" <file>`처럼 따옴표 밖에 파일명을 두면 공백이 1칸이 된다. GNU coreutils는 1칸도 받아주지만 Alpine 같은 busybox 환경에서는 형식 오류가 날 수 있다
- **주의**: `<file>`은 현재 디렉터리 기준 경로다. 파일이 있는 디렉터리에서 실행한다
- **주의**: macOS에 `sha256sum`이 없으면 `shasum -a 256 -c -`로 바꾼다. `-a 256`을 빼면 SHA-1로 계산된다
- **주의**: 체크섬은 파일 손상만 잡는다. 해시값과 파일을 같은 곳에서 받았다면 둘 다 바꿔치기된 경우는 잡지 못한다
