# DevOps Toolbox

DevOps/SRE 업무에서 반복적으로 사용하는 운영 명령어를 상황별로 찾아보고 재사용할 수 있도록 정리한 개인 기술 레퍼런스입니다.

명령어만 나열하는 대신 **언제 사용하는지, 어떤 옵션이 중요한지, 주의할 점과 다음 확인 단계는 무엇인지** 함께 기록합니다.

## 주요 기능

- 기술 영역별 명령어 정리
- 장애 증상과 작업 목적을 기준으로 한 상황별 역색인
- 브라우저에서 전체 명령어를 검색
- 명령어 복사 기능
- `navi`를 이용한 터미널 기반 퍼지 검색
- Markdown 원본으로 HTML 및 navi 치트시트 생성

## 기술 영역

Kubernetes · GitLab · Docker · NGINX · Prometheus · Loki · Linux · systemd · SSH · DNS · Java · Skopeo · Checksum · Bulk Edit

## 빠른 시작

### 브라우저에서 사용

저장소의 `index.html`을 내려받아 브라우저로 열면 됩니다. 별도의 서버나 외부 라이브러리 없이 사용할 수 있습니다.

### 로컬에서 다시 빌드

Node.js가 설치된 환경에서 실행합니다.

```bash
node build.js
```

`commands/*.md`가 원본이며, `index.html`과 `navi/toolbox.cheat`은 빌드 결과물입니다. 생성 파일을 직접 수정하지 말고 Markdown 원본을 수정한 뒤 다시 빌드합니다.

### 터미널에서 navi 사용

`navi` 설치 후 `navi/toolbox.cheat`을 navi의 cheats 경로에 연결하면 터미널에서 퍼지 검색으로 명령어를 선택할 수 있습니다.

## 저장소 구조

```text
commands/           영역별 명령어 원본(Markdown)
INDEX.md            상황별 역색인
build.js            Markdown → HTML / navi 생성 스크립트
index.html          브라우저용 검색 인터페이스(생성물)
navi/toolbox.cheat  navi 치트시트(생성물)
```

## 항목 작성 기준

각 항목은 다음 내용을 중심으로 작성합니다.

- **명령어:** 실행 가능한 예시
- **언제:** 어떤 상황에서 사용하는지
- **주의:** 옵션의 의미, 환경별 차이, 실수하기 쉬운 부분
- **연관:** 이어서 확인할 명령어나 관련 항목

실제 환경에 종속되는 호스트, 계정, 경로, 토큰 등은 플레이스홀더로 대체합니다. 명령어를 실행하기 전에 현재 환경과 권한, 대상 리소스를 확인하세요.

## 공개 범위 및 면책

이 저장소의 명령어는 학습과 참고를 위한 예시입니다. 운영 환경에 그대로 실행하기 전에 명령어의 영향 범위와 대상 리소스를 검토해야 합니다. 특히 삭제, 재시작, 설정 변경 명령은 사전 백업과 변경 승인 절차를 확인하세요.
